parts‑master.io

This is the starting scaffold for the site. Replace the contents of site/ and every push to develop publishes the result automatically.

Static by default

Plain HTML and CSS, no build step and no dependencies. Nothing to install, nothing to keep patched.

Deploys from develop

A push to develop triggers the Actions workflow, which uploads site/ and publishes it to Pages.

Room to grow

Adding a generator later means running it in the build job and pointing the upload at its output directory.

Deployed by GitHub Actions from .github/workflows/deploy-pages.yml
